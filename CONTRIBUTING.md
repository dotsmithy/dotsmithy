# Contribuir a dotsmithy

¡Gracias por pasarte! 🙌

Lo básico para abrir un PR:

- Tu rama sale de **`main`** y se llama **`feat/<algo-descriptivo>`**.
- Tu PR va a **`next`**, la rama por defecto (GitHub te la propone sola).
- El título del PR es un **Conventional Commit** en inglés (`feat: ...`, `fix: ...`,
  `docs: ...`). Un check lo comprueba.
- Si aún no está para revisar, ábrelo como **Draft**.

Si encuentras un fallo o se te ocurre una mejora, abre una
[issue](https://github.com/dotsmithy/dotsmithy/issues).

## Las guías

- [Cómo se trabaja en el repo](contributing/workflow.md): ramas, pull requests,
  checks, issues y la plantilla de contenido.
- [El entorno de desarrollo](contributing/development.md): el devbox, los tests y el
  Lab.
- [Escribir documentación](contributing/documentation.md): dónde va cada cosa, el
  tono, el formato y cómo se ve en la web.
