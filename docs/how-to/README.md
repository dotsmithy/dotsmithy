# Guías

Recetas para hacer algo concreto. Dan por hecho que ya tienes una máquina montada
con dotsmithy; si no, empieza por el [tutorial](../tutorials/first-machine.md).

- [Añadir un dotfile](add-a-dotfile.md): poner un fichero de configuración bajo
  control de dotsmithy.
- [Preparar una máquina nueva](create-a-profile.md): darle su perfil y su capa.
- [Instalar paquetes](manage-packages.md): listas por capa y repos COPR.
- [Escribir un hook](write-a-hook.md): ejecutar tus scripts en el momento justo.
- [Traer recursos externos](use-externals.md): repos o ficheros que no viven en tu
  contenido.
- [El día a día: actualizar y sincronizar](update-and-sync.md): llevar los cambios
  de una máquina a otra.

Para el detalle de cada opción, tira de la [referencia](../reference/README.md).
