# dots completion

Genera el script de autocompletado para tu shell.

Genera el script de autocompletado de dots para la shell que elijas.
Mira la ayuda de cada subcomando para ver cómo usar el script generado.

## Uso

```
dots completion [comando]
```

| Comando | Qué hace |

## Opciones globales

| Opción | Qué hace |
| --- | --- |
| `-n`, `--dry-run` | enseña qué haría sin tocar nada |
| `-h`, `--help` | enseña esta ayuda |
| `-v`, `--verbose` | saca más detalle de lo que va pasando |
| `-y`, `--yes` | no pregunta nada (modo no interactivo) |
